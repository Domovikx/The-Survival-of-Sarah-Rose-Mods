# Агенты

Определения кастомных агентов. Каждый `.md` файл описывает агента с frontmatter.

**Документация:** https://opencode.ai/docs/agents/

**Формат:**

```text
---
description: Что делает агент
mode: subagent
---
Системный промпт...
```
