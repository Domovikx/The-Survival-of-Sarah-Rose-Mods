# Глоссарий zh: единые написания

Титулы и имена — как в каноне `msgctxt speaker-name`; термины — один вариант на корпус.

- Captain Belmont → 贝尔蒙特船长 (он капитан корабля, не полковник)
- Captain (корабля) → 船长
- Captain of the guard / Guard Captain → 卫队长
- Lord → 领主 (если титул земли) / 大人 (обращение)
- King Orwell Rose → 奥威尔·罗斯国王
- Sarah → 莎拉
- Kate → 凯特
- Thomas → 托马斯
- Varga → 瓦尔加
- authorities → 官府 / 当局
- smuggler → 走私贩
- sergeant → 中士
