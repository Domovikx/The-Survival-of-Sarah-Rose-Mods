# MAP — local-dash

Факты и грабли (симптом → причина → проверено → что делать).

- **Страница «ест ресурсы» сама** → `nvidia-smi` (~100 мс) и особенно
  `powershell Get-Process` (~300–500 мс) на каждый тик при обновлении раз в 2 с.
  Проверено 2026-11-15. Что делать: кэш в коде — GPU 3 с, процессы 6 с;
  счётчики `po` (файлы по 15 МБ) — 60 с по mtime. Не уменьшать кэш «для
  свежести»: свежесть даёт 2-секундный опрос `/api/state`, а не тяжёлые вызовы.
- **`127.0.0.1` в `fetch`, а не `localhost`** → на Windows `localhost` может
  резолвиться в IPv6 и висеть до таймаута. Проверено на других сервисах
  (2026-10). В коде всюду `127.0.0.1`.
- **`po` считаем «msgid минус один»** → первая запись `msgid ""` — заголовок
  файла, не строка игры. Если не вычесть, проценты врут на 1/69 120 (мелочь,
  но в пульте видно).
- **Очередь показывает «—», хотя прогон идёт** → смотрим не процесс, а
  `tmp/translate_queue.json`; файл пишется только очередью
  (`translate_queue.mts`). Если гоняли `translate_run.mts` вручную — статус
  пустой, это норма (смотреть `tmp/translate_<lang>.run.log`).
- **Порт занят** (`EADDRINUSE`) → уже запущен другой экземпляр пульта; либо
  закрыть его, либо `--port`.
