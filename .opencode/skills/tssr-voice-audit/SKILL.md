## Что делаю

Проверяю весь корпус `patches/ai-voice-pack/audio/{ru,en}/` против PO и
свежей игры: не озвучен ли кто не тем голосом, не лежат ли файлы вне своей
арки (рантайм ищет строго `{lang}/{arc}/` → чужая арка = молчание), не выпали
ли строки. Лечу найденное штатными режимами скрипта.

## Источники истины

- `casts/casts.mts` (`SPEAKERS`, `LINE_OVERRIDES`) — спикер → каст/голос;
- `po/template.pot` — фразы, категории, арки (регенит `npm run potgen` из
  `game/`);
- свежая игра `<игра>/game/*.rpy` — единственное сырьё (скан
  `potgen.scanGame`);
- **`mods/`, `label_arc.json`, `voice_list.json` — артефакты сборки, НЕ
  источник** (сверяться с ними нельзя).

Ключ: `uid = md5(old)`; суффикс файла `{uid}__{variant}.opus` = вариант =
имя каста.

## Скрипт

`patches/ai-voice-pack/tools/generate/scripts/voice_role_audit.mts` —
резолюция 1-в-1 с батчем (импорт `loadCatalog`/`voiceForSpeaker` из
`voice_batch.mts`), поэтому расхождений «логика генерации vs логика аудита»
быть не может.

| Режим                     | Что делает                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| _(без флагов)_            | отчёт обеих языков + полные находки в `tmp/role_audit.json`                               |
| `--lang ru`               | один язык                                                                                 |
| `--verify [--game <dir>]` | POT ↔ свежая игра: дрейф (нужен ли potgen) + STALE жив/мёртв по сырью                     |
| `--delete`                | удаление WRONG_ROLE/VOICELESS/NON_SPEECH/STALE; со `--verify` щадит STALE с живой строкой |
| `--fix-arc`               | перенос ARC из чужой арки в POT-арку (rename; занятый приёмник = пропуск)                 |
| `--dry`                   | план без правок ФС (сочетается с `--delete`/`--fix-arc`)                                  |

## Workflow

1. `npm run speakers:audit` — целостность мапы «спикер → каст» (148/148).
2. `node patches/ai-voice-pack/tools/generate/scripts/voice_role_audit.mts`
   — отчёт корпуса по классам.
3. `node .../voice_role_audit.mts --verify` — сверка с сырьём:
   - POT ≡ игра (0/0) → potgen не нужен;
   - «только в игре > 0» → регенерировать POT (`npm run potgen`) и повторить;
   - STALE: uid жив в игре → файл НЕ удалять (POT потерял строку);
     строка исчезла из игры → файл мёртв навсегда.
4. Лечение (только с явного разрешения владельца):
   - `--delete` — мёртвые классы (STALE по подтверждённому `--verify`,
     WRONG_ROLE/VOICELESS/NON_SPEECH);
   - `--fix-arc --dry` → показать план владельцу → `--fix-arc` (перенос ARC,
     включая копирование в обе арки для мультиарочных uid).
5. Контроль: при изменениях генерации — `npm run test:voice:e2e`; после
   правок корпуса — пересборка дистрибутива `npm run build:pack`
   (установка синхронизируется ТОЛЬКО сборкой, вручную в установку не пишем).

## Классы

| Класс      | Значение                                                   | Лечение     |
| ---------- | ---------------------------------------------------------- | ----------- |
| OK         | суффикс ∈ ожидаемым голосам, арка верна                    | —           |
| WRONG_ROLE | файл под чужой ролью (главный баг-класс инцидента 2026-10) | `--delete`  |
| VOICELESS  | спикер осознанно без голоса (`null` в SPEAKERS), файл есть | `--delete`  |
| NON_SPEECH | uid = menu/ui/имя, а файл озвучен                          | `--delete`  |
| STALE      | uid в POT нет (строка выпала/текст изменился)              | `--delete`  |
| ARC        | верный голос, файл не в той арке (в игре молчит)           | `--fix-arc` |
| WEIRD      | имя файла вне формата `{32hex}__{variant}.opus`            | вручную     |

## Правила безопасности

- Инструмент правит ТОЛЬКО репу — установка синхронизируется сборкой
  дистрибутива (`npm run build:pack`) и установкой zip.
- `--delete` трогает только мёртвые классы; `--fix-arc` ничего не удаляет и
  не перезаписывает (занятый файл-приёмник = конфликт, пропуск).
- `--dry` везде печатает план, не трогая ФС.
- Покрытие корпуса (сколько вообще должно быть файлов) — НЕ этот инструмент:
  `voice_status.mts`.
