Единый справочник имён, титулов, UI-конвенций и стилевых правил. Переводчик
(в т.ч. сабагент, работающий над файлом или его порцией) обязан сверяться
с этим файлом: один и тот же термин переводится одинаково во всех сценах и арках.

Источник истины для имён — `patches/ai-voice-pack/tl/ru/misc_strings.rpy`
(там уже зафиксированы 155 переводов). Этот файл — сжатая выжимка правил.

## UI-конвенции

Клавиши и символы остаются идентичными оригиналу (конвенция существующего tl,
такие строки вернутся из переводчика с `new == old` — это норма):

- Enter, Escape, Ctrl, Tab → без перевода
- Page Up, Page Down, Start, Guide → без перевода
- `<`, `>`, `{#quick_page}Q`, `{#auto_page}A` → без перевода

Переводятся:

- Space → Пробел
- Arrow Keys → Клавиши со стрелками
- D-Pad, Sticks → Крестовина, Стики
- Gamepad → Геймпад
- Keyboard → Клавиатура
- Mouse Wheel Up / Down → Колёсико вверх / вниз
- Left Click / Right Click / Middle Click → Левый клик / Правый клик / Средний клик
- Preferences → Настройки
- Scene Replay → Повтор сцены
- Select a Category → Выберите категорию
- Main Menu → Главное меню
- History → История
- Quick saves → Быстрые сохранения
- Automatic saves → Автоматические сохранения

Формат даты (плейсхолдеры сохраняются, порядок компонент — по-русски):

- `{#file_time}%A, %B %d %Y, %H:%M` → `{#file_time}%A, %d %B %Y, %H:%M`

## Стиль перевода

- Эллипсис в репликах — три точки слитно: `...` (не `…`, не `. . .`)
- Текстовые теги и интерполяции Ren'Py сохранять один в один: `{i}`, `{/i}`,
  `{a=...}...{/a}`, `{#метка}`, `[имя_переменной]`, `%d`, `%s` — плейсхолдеры
  обязательны к сохранению (import-валидация их проверяет)
- `\\n` внутри строки — сохранять как есть (перевод однострочный)
- Род глагола при «ты», формальность «ты/Вы», 18+ тональность и эвфемизмы —
  по правилам из `SKILL.md` этого скилла
- Не переводи имена файлов, имена переменных и код внутри `[...]`-выражений
