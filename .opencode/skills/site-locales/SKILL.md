# site-locales — локали лендинга

## Что где живёт

| Файл                                              | Что это                                                               |
| ------------------------------------------------- | --------------------------------------------------------------------- |
| `site/src/shared/config/i18n.locales.ts`          | **только тексты**: ключ = английский текст, значения — 10 языков      |
| `site/src/shared/config/i18n.types.ts`            | типы, `dict()` (полнота языков), `localize()`, `MessageKey`           |
| `site/src/shared/config/i18n.ts`                  | рантайм: `i18next.init`, `MESSAGES`, `setLang`, `tPhrase`             |
| `site/src/widgets/demo/ui/DemoPhrases.phrases.ts` | **сгенерировано из po**: демо-фразы + имена спикеров (отдельный кейс) |
| `site/e2e/locales.spec.ts`                        | механическая перепроверка: пустые строки, `{{name}}`, мёртвые ключи   |
| `site/e2e/demo.spec.ts`                           | демо-фразы = `po/<lang>.po` (текст и спикеры), связка «текст + опус»  |
| `site/e2e/structure.spec.ts`                      | локали = только тексты; демо-фразы не в общем каталоге                |

## Команды (из корня репы)

```bash
# 1. Выгрузка всех ключей на вычитку (ключ + 10 языков, блок на ключ)
node .opencode/skills/site-locales/dump_locales.mts > tmp/locales_review.txt

# 2. Демо-фразы: перегенерация из po (по фразам/именам — источник po, порядок — `demo-manifest.json` в этом же скилле)
node .opencode/skills/site-locales/gen_demo_phrases.mts

# 3. Проверки
cd site && npx tsc --noEmit -p tsconfig.json
cd site && npx playwright test e2e/locales.spec.ts e2e/demo.spec.ts e2e/structure.spec.ts
```

## Правила

- **Демо-фразы не переводятся на сайте.** Их текст и имя спикера берутся из
  `patches/ai-voice-pack/po/<lang>.po` — из этих же msgstr сделан звук
  (uid = md5 английского текста). Правка руками = страница врёт против аудио.
  Меняем перевод в po → `gen_demo_phrases.mts` → тесты.
- **Ключ — английский текст**, `en` в значениях не дублируется.
- **Переводить нечего — не ключ**: Steam, Nexus Mods, Boosty, Ko-fi,
  `CC BY-NC 4.0`, `18+` живут в компонентах литералами.
- **Терминология — одна на весь сайт** (см. MAP: глоссарий по языкам).
- Демо-реплики и имена спикеров в общий каталог не кладём (страж
  `structure.spec.ts`).

## Вычитка: порядок

1. `dump_locales.mts` → `tmp/locales_review.txt`.
2. Читать блоками по ~330 строк (10 ключей × 11 языков) — так проще держать
   в голове контекст.
3. Правки вносить точечно (ключ + язык), с проверкой терминов по глоссарию MAP.
4. После правок: `tsc` + три спеки + `npm run build` (CSS должен остаться тем же
   по хешу, если правили только текст).
