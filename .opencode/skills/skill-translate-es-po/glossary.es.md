# Глоссарий испанского перевода TSSR (es.po)

Один термин — один перевод. Имена персонажей **не переводятся** (как в ru);
титулы перед именем — переводятся. Генерируется из `po/template.speakers.mts`
(список спикеров POT); ручные правки — только с вердиктом владельца.

## Имена (не трогать)

Все имена из POT-спикеров пишутся как в оригинале: Sarah, Kate, Alaric,
Samayra, Carolyn, Razaphel, Metis, Xanthippe, Maeiv, Sakar, Sigmund, Alfred,
Jaeid, Garret, Vaelen, Varga, Atilla, Marion, Dalia, Hecate, Marius, Thomas,
Lily, Cassius, Gilead, Gideon, Nickolas, Kravel, Daemon, Hassar, Sophia, Kim,
Jasmine, Naydeen, Albert, Hugh, Damian, Eula, Ephraim, Oryon, Mary, Gabriel,
Raza, Caleb, Dio, Ramsey, Matthew, Tirion, Ayaka, Elsa, Barion, Kamal,
Miriam, Nathan, Orwen, Jacob, Krip, Romanov Twin.

Особые: `King-On-The-Outside` — титул-прозвище, писать `Rey-De-Fuera`
(переводится, это не имя); `Voice` (говорящий голос в темноте) — `Voz`.

## Роль-спикеры (общие)

Narrator → нарраторская речь без «el narrador» (просто текст); Soldier/Guard/
Man/Woman/Girl — по контексту сцены (`soldado`, `guardia`, `hombre`, `mujer`,
`chica`).
