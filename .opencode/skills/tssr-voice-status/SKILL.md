# Статус генерации озвучки TSSR

ЕДИНЫЙ тул для статуса/прогноза — не считай вручную (find/wc/grep по ai_voice — нет, это дублирование и ошибки).

> **Движок генерации с 2026-11 — VoxCPM2 (полная миграция с CosyVoice3).**
> Текущие прогоны идут через `voice_batch.mts --engine voxcpm2` с общим логом
> `batch.log` — статус/прогноз смотри ПУЛЬТОМ (`voice_ctl.mts status`, раздел
> «Контур VoxCPM2» внизу). Тул `voice_status.mts` ниже — CosyVoice3-контур
> (легаси: им озвучен старый полный прогон RU/EN), новые прогоны он не видит.

## Когда вызывать

Пользователь спрашивает:

- «статус?», «как идёт генерация?», «сколько готово?», «прогноз?», «когда закончится?»
- «какие арки готовы?», «что сейчас генерится?»
- «проверь здоровье» (воркеры, tmp-сироты)

## Команда

```bash
node tools/generate/scripts/voice_status.mts       # полный отчёт + замер (~70 с)
node tools/generate/scripts/voice_status.mts --fast  # быстро (~6 с), без замера
node tools/generate/scripts/voice_status.mts --arc Other        # точечно: по конкретной арке
                                                #   (RU/EN, по голосам, размер)
node tools/generate/scripts/voice_status.mts --char Sarah       # точечно: по персонажу
                                                #   (план фраз, сделано, по аркам)
node tools/generate/scripts/voice_status.mts --detail           # подробный: арки×проценты×размер,
                                                #   топ голосов, вокеры, сироты
```

(Тул портирован на TS 2026-10-22; python voice_status.py удалён как легаси —
семантика команд и флагов та же.)

## Что выводит тул

- План: 134 534 фразы (67 267 озвучиваемых × RU+EN)
- RU/EN: сколько готово (стемы `.opus`/`.wav` — сейчас в корпусе только opus; пара wav+opus = один), %, размер (оба формата)
- Арки: сделано/всего, завершённые помечены ✓
- Вокеры: число voice_batch-процессов (node, до 2 очередей), активная арка (из логов gen_all_{ru,en}.log)
- Здоровье: tmp-сироты loudnorm (_.ln.tmp.wav — мусор от kill; с 2026-10-14 в ai_voice только opus, легаси-wav удалены, поэтому таких сирот не бывает) и недописанные_.part (обрыв конверта, атомарная запись — финалы целы)
- Скорость (замер прироста 60 с) → фраз/час, остаток, прогноз в часах/днях

## Как интерпретировать

- **Активная арка**: последняя START-метка в `output/voice/gen_all_{lang}.log` без DONE после неё
- **Скорость** волатильна (CPU делится с игрой/системой) — прогноз ориентировочный
- **tmp-сироты** появляются при kill/ребуте в окне ffmpeg→os.replace; финальные wav при этом НЕ страдают — это выяснено 2026-09-05. С 2026-10-14 новые файлы пишутся сразу в opus (`.part` → rename), а легаси-wav из ai_voice удалены — сироты `.ln.tmp.wav` там невозможны
- **Смешанный корпус** (легаси-wav + opus) считается корректно на случай возврата: стем с любым из расширений = одна готовая фраза; двойного счёта нет. Сейчас корпус — только opus
- Ускорение: добавить воркеры (до 4), но CPU забивается; или резать по аркам (`--arc`)

## Контекст

Очереди: `tools/voice_queue.sh {ru|en}` (bash, resumable, низкий приоритет, переживают ребуты).
Логи: `output/voice/gen_all_{ru,en}.log`. Рестарт после ребута — см. AGENTS.md.

## Контур VoxCPM2 (ОСНОВНОЙ, все языки, 2026-11)

**Генерация полностью на VoxCPM2** (миграция с CosyVoice3 завершена —
`cosyworker.py`/CosyVoice3-секции ниже и в AGENTS = легаси старого прогона
RU/EN, нового на них НЕ гоняем).

- Запуск: `node tools/generate/scripts/voice_batch.mts --engine voxcpm2 --lang <l> --demo`
  (демо-скоуп = 1188 игровых фраз + 7 витринных = 1195 файлов на язык; без
  `--demo` — полный проход; классические очереди `vox_queue.mts`/
  `voxcpm_bench.mts` — тоже легаси-путь).
- Лог ОБЩИЙ на все языки: `output/voice/batch.log` (не `vox_gen_*.log`!).
  Прогресс — строки `HH:MM:SS [n/m] uid Arc Who: ...`, свой прогноз — в строках
  `saved ... eta ~N мин`. Замер скорости: ~215–250 фраз/час.
- Статус/пауза/стоп — пульт `node tools/generate/scripts/voice_ctl.mts status`
  (видит ОБА контура: подхватывает `voice_batch.mts --engine voxcpm2 --lang <l>`,
  показывает арку/прогресс/ETA из batch.log; пауза/стоп — `voice_ctl.mts
vox-pause|vox-stop <lang>`). Ручной подсчёт файлов — не нужен.
- `voice_status.mts` (тул выше) — легаси-инструмент CosyVoice3-контура; для
  текущих прогонов источник истины — пульт + batch.log.
