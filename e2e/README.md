# E2E — протоколы и проверки патча TSSR

Живые E2E-протоколы и их скрипты (переиспользуемые артефакты проверок). Разовые
журналы — в `tasks/`, спеки — в `specs/`, юнит-тесты — рядом с кодом (`*.test.mts`,
`patches/ai-voice-pack/tests/`) — см. «Политика тестов» ниже.

## Быстрый старт E2E-прогона

1. Сборка и установка (как пользователь):
   - `npm run build:pack` → `dist/*.7z` (7z `-mx=9`; сборка сама гоняет `7z t`);
   - **`TSSR-AI-Voice-Pack-main.7z` → его `install.cmd`** (ядро: тексты 11
     языков, шрифты, меню; `ai_voice/` не трогает);
   - **каждый нужный `voice-<lang>.7z` → ЕГО `install.cmd`** (один язык,
     атомарно; без ядра установщик попросит сначала поставить main);
   - игра должна быть закрыта — установщик ждёт её закрытия до 3 минут;
   - проверить весь этот путь целиком, с нуля, можно одним скриптом:
     `bash e2e/user_flow.sh` (скачивает ассеты из релиза, сверяет sha256 с
     описанием релиза, кликает install.cmd'ы, запускает игру).
2. Скриншоты/запуск: `patches/ai-voice-pack/tools/generate/scripts/shots_capture.ps1`
   - `-Mode menu|game|all`, `-Lang <код|all>` (en ru de es fr it ja ko pl pt zh);
   - харнесс `zz_capture.rpy` живёт в `<игра>/mods/_tssr-test/` на время съёмки;
   - результат: `tmp/shots/{lang}_{menu,settings,dialogueN}.png`.
3. Логи: `<игра>/log.txt` (перед прогоном — ротировать: `mv log.txt log.txt.bak`;
   после — `grep -icE "exception|traceback" log.txt` обязан дать 0).
4. Сейвы: `%APPDATA%\RenPy\TheSurvivalofSarahRose-1625513096\` — карта сейвов по
   сценам: `node e2e/saves_map.mts` (сейв = ZIP; читает label-сцены).

## Чек-лист E2E-кейсов (матрица = en (нативный) + 10 переводов)

- [ ] K-E1 меню переведено на выбранном языке (включая en).
- [ ] K-E2 переключение языка в меню → переводы подъезжают везде (диалоги, UI, меню)
      на КАЖДОМ из 11 языков.
- [ ] K-E3 звук соответствует языку (`ai_voice/{lang}`, у en — свой набор);
      нет аудио → молчание без крашей.
- [ ] K-E4 демо-скоуп играбелен до ChooseThePath включительно (крючки: смерть отца,
      «Кто захотел навредить папе?», тизеры Кейт/Варга, первый выбор).
- [ ] K-E5 переключение между любыми языками (в т.ч. на/с en) — ничего не ломается.
- [ ] K-E6 полный ru — сквозная играбельность с полной озвучкой.
- [ ] K-E7 за пределами демо на 9 языках — EN-оригинал (не пустота, не краш).
- [ ] K-E8 стабильность: длинная сессия, многократная смена языка, сейвы/загрузки.
- [ ] K-E9 шрифты: CJK-глифы читаемы ПРИ ЛЮБОМ активном языке (метки языков —
      шрифтом своей метки); спецсимволы/диакритика не висят квадратами.
- [ ] K-E10 ЖИВОЕ переключение языков без рестарта (баг 2026-11-11): войти под EN →
      панель: RU (надписи стали RU) → zh (надписи переведены) → de (переведены) →
      снова zh → ОК → главное меню: низ с названием игры на выбранном языке
      БЕЗ квадратов (CJK-шрифт обязан переключиться живьём). Прогонять в обе
      стороны: из CJK в латиницу тоже (метки не должны «съехать» обратно).

## Скрипты

- `e2e/user_flow.sh` — путь ПОЛЬЗОВАТЕЛЯ с нуля на чистой Steam-установке:
  скачивание main+voice из Releases, сверка sha256 с описанием релиза, двойной
  клик `install.cmd` ядра и voice-пакета, предохранители, повторная установка
  поверх, запуск игры + `voice_debug.log` ([init], `catalog_loadable`).
- `e2e/saves_map.mts` — карта сейвов: какой сейв = какие сцены (для быстрых прогонов).
- `e2e/tl_dup_scan.mts` — дубли `old` в tl по языкам (Ren'Py падает на дублях:
  «A translation for X already exists»; инцидент 2026-11-11).
- `e2e/emo_judge_e2e.mts` — E2E-калибровка судьи тона (инъекции → recall/стабильность).
- `e2e/po2tl_parity.mts` — паритет шиппенного tl и свежесобранного из po.

## Политика тестов (сохраняем!)

- **TS-юнит-тесты** — рядом с кодом как `*.test.mts` (конвенция репо; их подхватывают
  typecheck-покрытие и `npm run typecheck`): `node --test <путь>`, полная матрица —
  `node --test $(find .opencode/skills patches/ai-voice-pack/tools patches/ai-voice-pack/casts scripts -name "*.test.mts" -not -path "*/node_modules/*")`.
- **Python-гарды** — `patches/ai-voice-pack/tests/` (pytest): сборка/раскладка/безопасность.
- E2E-скрипты здесь — не юнит-тесты, а проверки живого продукта (игра/аудио/POT);
  они тоже трекаются git и должны переиспользоваться, а не переписываться.
