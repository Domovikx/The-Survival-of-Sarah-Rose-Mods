# TSSR AI Voice Pack — Installer (Tauri 2)

Один `.exe` для Windows: находит игру в Steam, сам скачивает нужные `.7z` из
GitHub Releases в свою папку, распаковывает в `mods/tssr-ai-voice-pack/`,
показывает прогресс и лог. Официальная Steam-версия игры, Windows 10/11 x64.

**Статус: альфа.** Работает: поиск игры по Steam, инвентарь установки (ядро +
языки с числом файлов), скачивание выбранного с докачкой и прогрессом, SHA-256
файла, распаковка 7z **без внешнего 7-Zip**, полный uninstall (с сохранением
`environment.txt`, если есть чужие моды), переключение языка интерфейса
(11 языков, первичный — язык Windows), флаги языков и своя иконка приложения.

Языки — **тумблеры**: включён = язык должен стоять. Переключения копятся и
применяются одной кнопкой «Применить изменения» (удаление — только после
подтверждения), так что случайный клик не качает 20 МБ.

Ещё нет: проверка `checksums.txt` до распаковки, подпись exe (SmartScreen),
ожидание закрытия игры, проверка свободного места, длинные пути, обновление
поверх установленного.

## Почему Tauri, а не Electron/.NET/NSIS

- **Один файл без рантайма**: Chromium не тащим, WebView2 — системный
  (в Windows 11 встроен, на Win10 у подавляющего большинства есть; бутстраппер
  ~2 МБ, если нет).
- **TS-first**: UI и вся логика решений — TypeScript; Rust только I/O
  (реестр, сеть, распаковка, ФС). Логику можно тестировать без окна.
- **7z внутри**: `sevenz-rust` (чистый Rust) — пользователю не нужен 7-Zip.
- **Размер и доверие**: маленький exe выглядит приличнее 100-мегабайтного
  Electron'а и реже ловит эвристики антивирусов.

Отвергнуто: Electron portable (~100 МБ, AV-эвристики), .NET self-contained
(60–80 МБ и чужой стек), NSIS/Inno (UI-мастер без rich UI, логика на скриптах),
Node SEA (GUI нет).

## Сборка

Требования: Node 20+, Rust (stable, MSVC), MSVC Build Tools, WebView2 Runtime.

```bash
cd installer
npm install
npm run tauri build      # → src-tauri/target/release/
npm run tauri dev        # отладка с hot-reload UI
```

## Раскладка

```text
src/            TS: UI (main.ts), чистые данные и форматирование (core/)
src-tauri/      Rust: find_game (реестр+vdf+acf), download (Range+прогресс),
                extract (sevenz-rust), sha256_file, app_dir
```

Архивы качаются **в папку рядом с exe** (решение владельца): инсталлятор можно
перенести вместе с уже скачанными `.7z` на другую машину — офлайн-режим.

## Дальше по плану

1. Выбор компонентов (main обязателен + языки озвучки) и экран «что стоит».
2. `checksums.txt` в релизе (SHA-256) → проверка до распаковки.
3. Uninstall: удалить `mods/tssr-ai-voice-pack`, `environment.txt` — только если
   других модов нет.
4. Граничные случаи: игра запущена, мало места, нет сети, не-ASCII/длинный путь,
   Vortex-hardlink, UAC.
5. Подпись exe (SmartScreen) — отдельное решение владельца.

## Тесты

```bash
npm test      # vitest: план установки, форматтеры, полнота 10 переводов
npm run e2e   # собранный exe в режиме --selftest: core+EN → Remove EN → uninstall
```

`npm run e2e` качает ~35 МБ из последнего релиза и работает в `installer/tmp/e2e`
(реальную папку игры не трогает). Перед ним нужен `npm run tauri build`.
