## Что осталось непокрытым (по убыванию цены ошибки)

1. **`translate_queue`: спасение на нулевом прогрессе.** Сейчас язык может молотить
   30 пассов без прогресса (de — часы, fr — 3 часа молчания). Логика «2 пасса без
   прогресса → salvage → один пасс → следующий язык» не проверяется.
   _Как тестировать:_ вынести решение в чистую функцию (`shouldSalvage(passes,
progressDelta, empty)`) и покрыть; полный E2E требует переопределяемых путей po и
   бэкенда (сейчас `translate_queue` берёт `patches/ai-voice-pack/po` жёстко).
2. **`tssr_start_all`: идемпотентность.** Проверено руками (стоп → старт → по одному
   процессу), теста нет. Дёшево: вынести `missing(componentLines, known)` и проверить,
   что при живом процессе компонент не запускается второй раз (дубли очередей писали
   один po).
3. **`translate_pairfix` / `translate_clause_trim`.** Оба ходят в модель; для теста
   нужен мок-бэкенд — приём уже отработан в `translate_salvage.test.mts`.
4. **`voice_corpus.test`**: инвариант «один текст — несколько тонов» появился в
   `voice_stale`, но в корпусном тесте проверки нет.

- [ ] `missing()` в `tssr_start_all` покрыт тестом (живой компонент не запускается второй раз).
- [ ] `thermal_guard.mts` работает на равных с `.py` (dry-run сверен), `.py` удалён.
- [ ] `voice_push_chunked.mts` работает (dry-run `--chunk-mb`), `.py` удалён.
- [ ] `.cmd`-обёртки зовут `.mts`, а не `.py`.
- [ ] `MOD.md` / `AGENTS.md` не ссылаются на удалённые `.py`.
- [ ] Полная матрица `node --test` зелёная (кроме известных font/ui — они ждут сборки).
