«мы потом наверное заложим миграцию в отдельную папку с модом. я пока не пробивал эту тему но

целое а это не правильно. и нам придется в скором вренени продумать миграцию чтобы разделить
мод и исходники игры и тут нужно заводить таску вебсерчить и ресерчить углубленно как это
правильно делать. но пока в работу эту таску не берем еще работает второй агент над задачами.»

## Цель

Когда проект живёт «внутри» папки Steam-игры (`The Survival of Sarah Rose/` = официальные файлы

- наш мод + наш репозиторий вперемешку), любое обновление игры, чистка установки или перенос на
  другой ПК = боль. Хотим структуру, где мод — самостоятельный дистрибутив (отдельная папка/репо),
  который копируется в игру по инструкции, а разработка ведётся не в папке игры. Критерий успеха:
  есть вердикт с таблицей вариантов, как распределить код, и план миграции без потери текущего
  прогресса (перевод 100%, озвучка 94.2%, мод-слой в работе).

## Контекст (что есть сейчас)

- Репозиторий проекта лежит ВНУТРИ установки игры: `C:\Program Files (x86)\Steam\steamapps\common\
The Survival of Sarah Rose\` — здесь же `game/` официальной игры, `ai_voice/` (~1.6 ГБ),
  `mod/` + `environment.txt` (механизм подключения мода вне game/, ресёрч
  `tasks/2026-10-14-update-proof-mod-connection.md` — DONE).
- `game/tl/ru/` (перевод) и патчи `game/gui.rpy`, `game/options.rpy`, `game/screens.rpy` —
  прямо смешаны с официальными файлами; после апдейта Steam часть файлов слетает.
- Мод-слой в работе (`tasks/2026-10-14-mod-overlay-migration.md`, статус DOING — второй агент):
  кнопка на гл. меню → своё меню (языки/озвучка), официальные экраны не переопределяются.
- Озвучка: `ai_voice/` ВНЕ `game/`, подключается через `config.searchpath`
  (`game/voice_config.rpy`) — по сути уже «внешний» слой, кандидат на переезд в мод-пакет.
- В git репо попадает мусор установки (см. `git status`: `environment.txt`, `mod/`, `log.txt`,
  `traceback.txt`, `*.rpyc`, `nul`) — признак того, что «дом репозитория» не определён.
- Смежная работа уже идёт по разделению «мод vs официальные файлы» на уровне Ren'Py
  (мод-слой) — эта задача про уровень ВЫШЕ: раскладку папок/репозиториев/дистрибутива.

## Что сделать (ресёрч, по протоколу `tasks/AGENT.md`)

Вебсёрч обязателен (официальные доки Ren'Py → чужие мод-проекты → статьи). Вопросы ресёрча:

1. Как устроена типовая раскладка Ren'Py-мода для «чужой» игры: папка мода рядом с игрой vs
   отдельный репо + скрипт установки? Где Ren'Py ищет дополнительные файлы (searchpath,
   `config.search_directory`, `extra`-директории) — факты со ссылками на doc.renpy.org (дата
   сверки указать).
2. Формат дистрибутива: zip «мод + инструкция» vs установщик vs git-репо, который юзер клонирует
   в папку игры? Что делают сопоставимые проекты (NeonTranslator/Third Crisis — как ссылался
   человек; найти их структуру [УТОЧНИТЬ: попросить у человека ссылку, если не найдётся в вебе]).
3. Что делать с переводом `game/tl/ru/`: оставить как переопределение внутри game/ vs
   переезд в мод-пакет (Ren'Py умеет подключать tl из searchpath? проверить) — и как это
   соотносится с мод-слоем из `2026-10-14-mod-overlay-migration.md`.
4. Что делать с `ai_voice/` (~1.6 ГБ): включать в дистрибутив мода vs отдельный пакет
   озвучки (разные размеры/разные скорости обновления), какие пути в `voice_config.rpy`
   тогда меняются.
5. Репозитории: один репо (monorepo: `mod/`, `site/`, `tools/`, `catalog/`) vs разделение
   (мод-репо + репо инструментов)? Что с GIT LFS для `ai_voice`, какие лимиты GitHub
   (файл ≤ 100 MiB, репо рекоменд. ≤ 1-5 ГБ [УТОЧНИТЬ: сверить лимиты с доками GitHub]).
6. Разработка НЕ в папке игры: рабочая копия мода в `C:\dev\tssr-mod` + скрипт «sync в игру
   для теста» vs symlink vs Ren'Py-проект мода, запускаемый отдельно (как правильно: мод
   Ren'Py — это же папка с `game/`, которую докладывают к основной игре?).
7. План миграции без потерь: как перевезти `game/tl/ru`, патчи gui/options/screens (если они
   ещё нужны после мод-слоя), каталоги `catalog/`, `config/`, `tools/`, `tasks/`, `voice_candidates/`.
8. Обновления: как юзеру обновлять мод после выхода новой версии игры/мода (замена папки vs
   скрипт-апдейтер), как не потерять `environment.txt` при чистке установки.

Таблица вариантов ≥2 по каждому разделу — при выполнении; решение согласовать с человеком до
