# 2026-11-11 Сайт патча: локализация 11 языков, UX переключателя, обновление контента

Статус: DOING (взята в работу 2026-11-11)

## Задача от пользователя

«так мы можем продолжать работу над патчем? можем ли обновить инфу на сайте? его тоже надо
делать под наши языки? значит надо изменить немного UI/UX сайта для быстрого переключения»

## Цель

Сайт патча (`site/`, GitHub Pages) говорит на тех же 11 языках, что и мод (en-нативный +
10 переводов), с быстрым переключением языка; контент обновлён под текущее состояние патча
(11 языков, демо-скоуп, озвучка Vox, установка, донат-CTA).

## Контекст (что есть сейчас)

- Стек: React 19 + Vite + i18next/react-i18next + stylex, FSD (`src/app|features|shared|widgets`),
  Playwright e2e (`site/e2e`), деплой `gh-pages` (deploy-скрипт в package.json).
- `site/locales/` — только **en.json / ru.json** (~50 ключей) — 9 языков отсутствуют.
- `src/features/language-switcher` — переключатель уже есть (в sticky-хедере); UX под ревью.
- Ссылка «Сайт патча» из мода ведёт сюда (zzz_ui, 2026-11-11).

## Что сделать

1. Ревью LanguageSwitcher (UX): нативные имена языков (как в моде: English/Русский/Deutsch/
   日本語…), мгновенное переключение, сохранение выбора (localStorage), авто-определение
   языка браузера при первом визите, CJK-корректность. [УТОЧНИТЬ: формат — дропдаун vs
   сегменты; посмотреть текущий и решить по ревью]
2. Локализация 9 языков: `locales/{de,es,fr,it,ja,ko,pl,pt,zh}.json` (перевод ~50 ключей
   каждый; терминология = мод: «патч», «Сайт патча», донат-CTA как в zzz_ui).
3. Контент-обновление: 11 языков, демо-скоуп (до первого выбора), озвучка VoxCPM2,
   скриншоты/крючки, инструкция установки, донат-CTA (Boosty — основной; Ko-fi — резерв).
4. Проверки: `npm run build` (tsc+vite), `npm run test:e2e` (Playwright), визуальная проверка
   ключевых экранов на 4 сложных языках (ru/ja/ko/zh) + переключение туда-обратно.
5. Деплой — только по команде владельца (`npm run deploy`).
