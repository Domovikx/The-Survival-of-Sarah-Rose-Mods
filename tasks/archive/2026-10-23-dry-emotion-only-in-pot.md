# [2026-10-23] Убрать `#. emotion` из po/*.po: тон только в POT + резолвер po → pot[arc, scene, uid, emotion]

Статус: DONE (2026-10-23, вечер)

## Задача от пользователя

«запиши в тудушку, я нашел еще олин DRY #. emotion достаточно иметь только в pot а при озвучке
там будет браться обратный пайплайн po.msgid > pot[arc, scene, uid, emotion] . у нас гдето уде
есть скрипт в него только emotion добавить это пока достаточко оформить таской, и потом как то
сделаем и продон сделаем по e2e. это нам по DRY сделает хорошую экономию в N.po»

## Цель

Когда в N.po живут только переводы, а метаданные нужны только при озвучке/сборке, я хочу держать
тон (`#. emotion:`) единожды в `template.pot` и резолвить его обратным пайплайном
«po-запись (msgctxt+msgid) → pot[arc, scene, uid, emotion]», чтобы не дублировать 68 181 тон
на каждый из 10 языков. Критерий «стало лучше»: суммарный размер po/*.po меньше на ~23 MB,
источник тона один (POT), поведение озвучки и перевода не меняется.

## Контекст (что есть сейчас)

Проверено 2026-10-23:

- Источник тона — POT: `potgen.mts:58-62` (`#. emotion:` в шаблоне, roundtrip тона при регенерации),
  `potgen.mts:590` (запись), `potgen.mts:620-628` (uid → emotion). Структура комментариев POT —
  `arc → scene → uid → emotion` (`potgen.mts:40`).
- В .po тон течёт сегодня через `po_core.mts:151-159` (`keepEmotionComments` — «в .po только тон»,
  решение 2026-10-22) и `po_update.mts:11` («тон (#. emotion) освежён из POT» при `npm run po:update`).
- Прецедент БЕЗ тона уже был: `prefill.mts:20-21` — «ru.po пишется без #. uid/emotion —
  машинные метаданные живут только в template.pot». Т.е. решение владельца зафиксировано и раньше,
  но po_update снова начал тащить тон в po.
- «Уже есть скрипт с обратным пайплайном» = `voice_batch.mts:74-105` (`loadCatalog`): обходит POT,
  для каждой записи берёт `uid = md5(msgid)`, `arc`/`scene`/`category`/`emotion` из комментариев POT
  и подтягивает перевод из po по ключу `msgctxt\0msgid`. Чего не хватает: тон есть, но каталог
  захардкожен на `RU_PO_FILE` — нужен пер-языковой доступ, и резолв вынесен не как общий модуль.
- Новый `po_translate.mts` (создан 2026-10-23) читает тон ИЗ po-записи
  (`userPrompt`/`judge` — `entry.comments` «emotion:») — его надо пересадить на резолвер,
  иначе после чистки переводчик не увидит тон.
- Экономия (замер сегодня, `grep -c '^#\. emotion'`): 68 181 комментарий на po-файл = 2.3 MB
  на язык, **22.8 MB суммарно по 10 po**; в `template.pot` остаётся 68 181 (источник).
- Скелеты 8 новых языков (de, fr, it, ja, ko, pl, pt, zh) созданы 2026-10-23 и пока содержат тон —
  после задачи перевыпустить без тона.

## Журнал решения (2026-10-23)

Ресёрч: потребителей тона в po нашлось два — `po_translate.mts` (читал из
`entry.comments`) и сам `po_update` (тащил при merge); `voice_batch.loadCatalog`
тон уже брал напрямую из POT (эталон поведения, не менялся).

Сделано:

- **`renpy-po/pot_resolve.mts`** — общий обратный резолвер
  `po-запись → {uid, arc, scene, emotion, category, speaker}` по ключу
  (msgctxt, msgid); `uid = md5(msgid)` (та же формула, что `#. uid:` —
  комментарий как источник НЕ используется, формула едина); `null` при дрейфе.
  Юнит-тесты: `pot_resolve.test.mts` (6/6, включая боевой POT: AlfredArc /
  Thoughtfully puzzled).
- **`po_update.mts`**: в .po не течёт ничего (`e.comments = []`),
  док-комментарии обновлены; `keepEmotionComments` УДАЛЕНА из `po_core.mts`
  (потребителей не осталось).
- **Чистка 10 po-файлов** (`tmp/po_dry_cleanup.mts --apply`): удалено
  **681 810 комментариев = 22.8 MB** (по 2.3 MB на язык; es/ru в git:
  −136 362 строки). Повторный прогон — 0 (идемпотентно).
- **`po_translate.mts`**: тон через `loadPotIndex()` (резолвер), `--dry`
  печатает тон из POT.
- **Скелетер po_skeleton**: новые po создаются без комментариев.
- Тесты: **70/70** (`node --test renpy-po/*.test.mts`), `tsc` чист,
  `oxlint` 0 ошибок, round-trip всех 10 po байт-в-байт.
- Идемпотентность: `po:update --lang es` и `--lang ru` после правки —
  `grep '^#\. '` = 0, round-trip идентичен.
- Доки: `renpy-po/SKILL.md` (раздел «Метаданные озвучки» переписан),
  `AGENTS.md` (DRY-абзац в «Эмоции в генерации»).
- e2e-смоук: `voice_batch --lang ru --dry-run` — тон в плане на месте
  `[Nodding slowly, amused] ...` (паритет: читает POT напрямую, не тронут);
  `po_translate --lang es --dry` — тон из резолвера напечатан
  (`<- тон: In a hushed, shocked whisper`).

Приёмка: все пункты выше закрыты; экономия подтверждена.
