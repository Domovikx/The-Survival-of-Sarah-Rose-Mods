## Задача от пользователя

«VoxCPM2 заведи таску на ресёрч. интересует может ли он клонировать голос
и поддерживает ли он мультиязычность что у нас в po заявлена если да то
углубляем ресёрч, и я бы хотел его тоже скачать топ модель для 5070ti
16gb и попробовать что-то поконфижить и послушать» (2026-10-26).

## Цель

Двухступенчато:

1. **Фильтр (быстрый вебсёрч):** подтверждение (а) клонирования голоса по
   короткому рефу, (б) поддержки ВСЕХ 10 языков TSSR из `po/`:
   **de, es, fr, it, ja, ko, pl, pt, ru, zh**. Если хоть один пункт не
   закрыт — задача закрывается «отклонён», ресёрч не углубляется.
2. **Углублённый ресёрч + ЖИВАЯ ПРОБА:** скачивание модели под RTX 5070
   Ti 16 ГБ, локальный запуск, клонирование наших рефов из
   `patches/ai-voice-pack/casts/voices/`, слушательский A/B против
   CosyVoice3 на тех же фразах. Вердикт: «кандидат на замену / интересно
   на будущее / отклонён».

## Контекст

- VoxCPM2 (OpenBMB, 04/2026, **apache-2.0**, 2B параметров) — выжил в
  двойном фильтре (мультиязычность + бесплатная лицензия) в задаче
  `2026-10-26-tts-engine-alternatives-research.md`.
- Первичные факты (обзор pinggy.io 08/2026, не проверены нами):
  30 языков + 9 кит. диалектов, **48 кГц** выход, tokenizer-free
  (diffusion AR в AudioVAE V2 latent), **~8 ГБ VRAM, RTF ~0.30 на
  4090**, WER 1.84% (Seed-TTS-en) / CER 0.97% (zh hard), 36k GitHub
  звёзд, апстрим живой (коммиты еженедельно).
- Три режима клонирования (по обзору): Voice Design (по описанию текстом),
  Controllable Cloning (реф + style guidance), Ultimate Cloning (реф +
  транскрипт рефа — максимум деталей).
- Наш движок: CosyVoice3 (0.5B, apache-2.0), clone+emotion (instruct2),
  RTF 0.98, 974 фраз/ч на 5070 Ti. Корпус 134к фраз RU+EN уже
  сгенерирован; новые языки = расширение, смена движка = перегенерация.
- Наш пайплайн: TS-оркестрация + python-шим (протокол v2, JSON-lines),
  рефы 10с из casts/, пофразовый тон из POT (`#. emotion:`).
- Портовые особенности: llama.cpp-omni (GGUF, без PyTorch) и vLLM-Omni —
  оба заявлены; **vLLM не работает на Windows нативно** (закрытая задача
  бенча движка) → GGUF-путь llama.cpp-omni или PyTorch-инференс.

## Живая проба (ступень 2) — 2026-10-26

Окружение (всё в C:/tools/voxcpm2/, вне репы):

- venv: python 3.11 (uv), `voxcpm` из PyPI; **важно: uv поставил torch
  CPU-only — переставлен `torch==2.14.1+cu130`** (CUDA видит 5070 Ti);
- модель: openbmb/VoxCPM2 (2B, audiovae.pth + model.safetensors, ~5 ГБ)
  → C:/tools/voxcpm2/models/VoxCPM2;
- API-нюанс текущего voxcpm: `generate()` НЕ принимает `seed` (жёсткая
  сигнатура: text, prompt_wav_path/prompt_text, reference_wav_path,
  cfg_value, inference_timesteps, min_len/max_len, normalize, denoise,
  retry_badcase*) — seed в скрипте убран.

Проба (tmp/voxcpm2/voxcpm2_probe.py): Controllable Cloning рефом
`casts/voices/Sarah/Sarah.wav` (10с, без транскрипта), 4 фразы —
ru/en × plain/emotion (эмоция префиксом «(восторженный, радостный тон)»,
формат офиц. README). Сторона A — наш движок на тех же 4 фразах
(tmp/voxcpm2/cosy_probe.mts, instruct2, seed 42). Пары для слуха:
tmp/voxcpm2/compare/ (A=__cosy, B=__voxcpm).

**Скорость (5070 Ti):**

|                    | CosyVoice3 0.5B | VoxCPM2 2B            |
| ------------------ | --------------- | --------------------- |
| Загрузка модели    | ~26с            | ~28с                  |
| RTF после прогрева | 0.9–1.2         | 0.87–0.99             |
| Холодный старт     | фраза-прогрев   | фраза-прогрев (22.5с) |

Заявленный апстримом RTF ~0.3 НЕ достигнут: в логе `torch.compile
disabled - triton is not installed` — путь оптимизации есть (triton),
скорость и так сопоставима с нашей.
