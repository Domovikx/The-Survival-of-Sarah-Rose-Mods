### 2026-11-09: waves3 + разбор остатка — класс «склейки» найден и вылечен

waves3 (перевод 7 244 пустых + 3 итерации) — сходимость 471 → 259 → 202 флагов;

content, Inverted meaning, Gender mismatch, Added dialogue) + FP-потолки.

Ключевая находка — **класс «склейка наррации со следующей репликой»**
(fr/it/ja/zh[706] «Kate whispered to Sarah.» → модель вставляла выдуманную
речь из следующей строки): модель детерминированно повторяла брак
(0/14 успехов при ретраях), судья корректно отвергал. Лечение — усиленный
ретрай в `translate_run.mts` (2026-11-09):

1. обратная связь с причиной отклонения судьи в промпте ретрая;
2. формулировка «дословно, только слова этой строки; атрибуция речи — без
   цитаты, произнесённые слова идут отдельной строкой».
   **E2E-замер: 0/14 → 5/5 (fr), класс вылечен на fr/it/ja/zh.**

### 2026-10-25: НАЙДЕНА БАГА класса «символьный msgid → галлюцинация»

Симптом (по факту, все 10 файлов просканированы):

```po
msgctxt "ui"
msgid "<"
msgstr "《伦理学简史》作者：路凡"   # zh: судья поставил 10!
```

Замер скана классов аномалий по всем po: **A символьный ≠ идентичность: 16** (de/it `< ui >`,
ko/zh/pl — целые фразы-галлюцинации из соседнего контекста, pt `<\n\n>`; fr/ja/de оставили
пусто), **C чужая письменность: 2** (pl `Thomas`→`Томас`; es — одна кириллическая «е»
всередине испанского: `retuercе`), **D короткий→длинный: 1** (es `Load`→фраза-бред
про «Carga la mercancía»), **B msgstr==msgid с буквами: 10** (ru: `Ctrl`, `Enter`, `Escape`,
`Page Down` — НЕ бага, это и есть перевод для клавиш).

Корень (из jsonl): модель получает `EN: <` рядом с контекстом «A Brief Investigation on
Ethics» → выдумывает перевод из контекста; судья ставит 9–10, потому что считает
короткую EN-строку «too trivial». Для `>` срабатывает авточек `msgstr == msgid` → rejected
навсегда (цикл: ретрай бессмысленен).

Что фиксить (план; пункты 1–3, 5 выполнены 2026-10-25 — см. «ФИКС БАГИ» ниже):

1. `po_translate`: символьные msgid (нет букв) → пропуск LLM, `msgstr = msgid` сразу;
   авточек `msgstr==msgid` не должен ругаться на символьных.
2. `checkTranslation`: правило «символьный msgid → только идентичность».
3. Поискать аналоги: классы C (смешанная письменность внутри слова — unicode-guard!) и D
   (короткий UI → длинный бред) включить в авточеки.
4. Починить 16+3 уже испорченных записей (вручную/повторным переводом).
5. **Скилл-аудитор** (идея владельца 2026-10-25): отдельный скилл, главная цель — найти
   «в чём лажа» в УЖЕ переведённом: показать EN vs TR, класс проблемы, при ошибке —
   возвращать запись на перевод (`msgstr=""` + в очередь). Запускать сабагентом поверх
