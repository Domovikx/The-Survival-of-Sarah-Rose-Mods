# Остаточный триаж флагов судьи по po (после волны 2026-11-19)

**Статус:** READY
**Зачем:** волна судьи по выборке 1500 строк на язык дала 458 флагов; 1:1-ремонт
сделан, но 167 флагов остаются «bad» и требуют решения агентом (судья на тонких
местах ошибается в обе стороны — см. `translate/MAP.md`).

**Что осталось разобрать (файлы `tmp/bad_<lang>.txt` — исходные флаги):**

- `fr` 14, `de` 13, `it` 16, `ja` 12, `pt` 9, `es` 6, `ru` 13, `zh` 36, `ko` 29, `pl` 18.

**Как делать:** по каждому флагу прочитать пару EN↔TR из `po`; править только
подтверждённые ошибки (пол, инверсия смысла, выдуманный текст, потерянный
смысл). Ложные — фиксировать в MAP/аудите, не «переводить заново».

**Приёмка:** после триажа `translate_review <lang> --all` = 0, `po:check --all`
чист, аудит `voice_stale` по затронутым языкам = 0 устаревших; правки
закоммичены с перечнем подтверждённых дефектов.
