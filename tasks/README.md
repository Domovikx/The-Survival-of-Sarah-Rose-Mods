# Задачи TSSR: как брать и сдавать

Очередь работ так, чтобы любой агент мог взять один файл и выполнить его без дополнительных
вопросов. Обязательно к прочтению перед первой задачей: `tasks/AGENT.md` (ресёрч-first).

ВАЖНО: этот каталог НЕ попадает под .gitignore (проверено 2026-10-22: git check-ignore —
пусто) — файлы задач коммитятся наравне с кодом. Наряду с AGENTS.md: никаких коммитов
без явного разрешения владельца.

## Как взять задачу

1. Открой таблицу задач ниже или конкретный файл.
2. Статус должен быть `READY`. Статусы: `READY` → `DOING` → `DONE`. Перед стартом поменяй
   статус на `DOING` (правка файла; коммит не нужен — каталог вне git).
3. Прочитай целиком: «Контекст», «Что сделать», «Приёмка», «Вне рамок».
4. Статус/прогресс озвучки не трогать вручную: `python tools/voice_ctl.py status`.

## Правила выполнения (обязательно)

- Коммиты — ТОЛЬКО по явному разрешению пользователя (AGENTS.md, жёсткое правило).
- Выборы (формат, библиотека, параметры) — сначала ресёрч по `tasks/AGENT.md`, потом решение,
  потом код. Цифры «по памяти» запрещены — только замер/источник со ссылкой и датой.
- Тесты: `python -m pytest tests/ -v` (93 теста) должны остаться зелёными.
- Статусы воркеров/очередей: только `tools/voice_ctl.py`, ручной подсчёт файлов запрещён.
