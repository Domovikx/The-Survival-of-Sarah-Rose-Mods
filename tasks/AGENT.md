# Памятка агенту: сначала ресёрч, потом решение, потом код

Если в задаче есть выбор (формат, библиотека, параметры, цифры) — не гадай и не бери первое
попавшееся. Это обязательно, а не «по желанию».

## Протокол решения

1. **Сформулируй вопрос** одним предложением: плохо — «какой формат взять», хорошо — «что
   де-факто стандарт 2026 для голоса в играх: Opus vs Ogg Vorbis vs FLAC — вес, поддержка
   Ren'Py 8.5.4 (десктоп+web), влияние на наш пайплайн».
2. **Вебсёрч**: 2–3 запроса разными словами. Приоритет источников: официальные доки и спеки →
   исходники/CHANGELOG → сравнения с цифрами → статьи → мнения.
3. **Если вебсёрч недоступен** (403 из песочницы — бывает; так и было 2026-10-12): обход через
   DuckDuckGo HTML (`https://html.duckduckgo.com/html/?q=...`) + `webfetch` конкретных страниц.
   Каждый факт — со ссылкой и датой проверки.
4. **Замер обязательной для размеров**: на реальных файлах проекта через `ffmpeg` (8.1.2
   доступен) — на сэмпле ≥25 случайных `ai_voice/**/*.wav`, плюс оценка на весь корпус.
5. **Таблица вариантов** (минимум 2, иначе это не выбор, а назначение): список критериев из
   «Критериев» ниже, под каждым вариантом — его оценка.
6. **Метод исключения** (от наименее подходящего): вычёркивай по одному, причина в одну строку.
   Для финального варианта — отдельно преимущества, недостатки и условия, при которых решение
   перестанет быть верным. Выбор без разбора недостатков — не выбор, а реклама.
7. **Сомнения = дополнительный ресёрч**: ещё 1–2 источника, минимальный прототип-замер, чтение
   исходника. Снять сомнение «потому что кажется» запрещено. После 2 кругов сомнение живо —
   `[СОМНЕНИЕ: ...]` и человеку.
8. **Запиши решение** в задачу (секция «Приёмка»/«Результат»): таблица + вердикт + плюсы/минусы
   - ссылки + снятые и неснятые сомнения.

## Критерии оценки (в порядке важности для TSSR)

1. **Качество звука**: без потери качества — lossless; lossy — только с обоснованием
   прозрачности (слепой замер/тест), иначе instant reject.
2. **Совместимость с движком**: Ren'Py 8.5.4 — десктоп И веб-сборка (см. доки audio.html,
   `config.webaudio_required_types`). Непроверенная поддержка = не вариант.
3. **Размер дистрибуции**: сейчас ~21 GB (RU 10.8 + EN 10.2), 119 013 wav, mono 24 kHz
   16-bit — каждый вариант даёт свою цифру, только замером.
4. **Цена в пайплайне**: сколько правок в `voice_batch.py` / `voice_config.rpy` / тулах;
   двойное хранение (wav+формат) — минус.
5. **Проверяемость**: можно ли покрыть замером/тестом, а не «верьте мне».
6. **Цена владения**: open/royalty-free лицензия, живёт ли кодек, поддержим ли сами.

## Что нельзя

- Брать факты/цифры «по памяти» без пометки `[УТОЧНИТЬ]`.
- Снимать сомнение ощущением — только факт, замер или исходник.
- Выбирать «потому что популярно» без таблицы по критериям.
- Молча менять контракт пайплайна (пути, манифесты) — сначала согласование с человеком.
- Начинать конвертацию/миграцию файлов до явного «делай» — ресёрч ≠ исполнение.

## Контекст проекта (читать до любых вопросов по звуку)

- `AGENTS.md` — архитектура озвучки, uid = md5(old), раскладка ai_voice/, правила.
- `game/voice_config.rpy:87,95-96` — рантайм-поиск жёстко `*.wav` (glob) — смена формата
  трогает эти строки.
- `tools/voice_batch.py:143,185` — пайплайн генерации пишет `{uid}__{variant}.wav`.
- Замер 2026-10-12 (сэмпл 25 файлов, ffmpeg 8.1.2): FLAC = 59% от WAV, Opus 48k = 12.2%
  → проекция на 21 GB: ~12.4 GB / ~2.55 GB (проверить на большем сэмпле).
- Ren'Py 8.5.4 доки (сверено 2026-10-12): Opus, Ogg Vorbis, MP3, MP2, FLAC, WAV (16-bit
  signed PCM only); auto-namespace включает `.wav .mp2 .mp3 .ogg .opus` — `.flac` там НЕТ
  [важно для способа подключения файлов].
