- **Кастинг шрифтов**: `tmp/font_casting/index.html` — 23 кандидата

  все с кириллицей (Google Fonts, нужен интернет). Победитель → `mod/fonts/`
  (геймпатч указывает `fonts/…` — резолвится через RENPY_SEARCHPATH).
- **Размеры шрифтов**: числовые input-поля (`allow "0123456789"`, `length 3`,

  когда изменений нет», Apply vs Save): чисто → [Закрыть]; есть правки →
  [Отменить правки] + [Применить и перезапустить] — безмолвного discard нет.
  Esc = зеркало подвала. «К стандартным» (в секции) — сброс черновика.
  Язык/озвучка — radio-пары, применяются мгновенно (официальные стили
  `radio_button`, SetMute/Language сами перезапускают интеракшен).
- **Секция «Ссылки»**: GitHub-звёздочка (`OpenURL`, репо из README-бейджа),

ShowMenu("tssr_mod_menu")]` — порядок «снапшот → execute» гарантирован
