# The Survival of Sarah Rose — AI Voice & Localization (unofficial patch)

Unofficial fan-made localization (11 languages) and AI voice-over packs for
**The Survival of Sarah Rose** (Ren'Py, Steam).

**Project page (source of truth for users):** <https://domovikx.github.io/>
**Nexus Mods:** <https://www.nexusmods.com/games/11043/mods/1>
**Downloads:** [GitHub Releases](https://github.com/Domovikx/The-Survival-of-Sarah-Rose-Mods/releases)

Installation, file list, language matrix, FAQ and screenshots live on the site
and the Nexus page (each archive also carries `INSTALL.txt` with the same
steps). This file intentionally keeps only what is needed to stay safe and
legally clear.

## What this is

- Translation texts, mod menu and UI for the game — in 11 languages.
- Separate voice packs: **AI-generated (synthetic) voice-over**, demo scope
  (opening arcs). Voices are cloned/generated by AI, they are **not** recordings
  of real people.
- Fonts needed to render the translated text (Literata, Noto CJK; both under
  the SIL Open Font License).

No game files are redistributed: the patch only adds its own folder
(`mods/tssr-ai-voice-pack/`) and one service file (`environment.txt`).
Removing the patch = deleting that folder.

## Requirements

- A legally purchased copy of **The Survival of Sarah Rose**. You need the game
  itself; this repository contains only the fan-made patch.
- Windows (Steam version of the game, Ren'Py 7.4.11).
- **Back up your saves** before installing. Saves are local — the game has no
  Steam Cloud for this title.
